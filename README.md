# 🤖 CapDragonfly (蜻蜓队长)

> **“第一，绝对不意气用事；第二，绝对不漏判任何一件坏事；第三，绝对裁判得公正漂亮！”**

**CapDragonfly** 是一个专为 AI 对话、自动化脚本及 Agent 交互设计的深度评分与审计系统。本项目通过构建多维度的评估矩阵，为 AI 的表现提供客观、可量化且具备可解释性的判准。

---

## ⚖️ 裁判核心逻辑：三大评估体系

本项目不只关注结果，更关注 AI 达成目标的“过程”与“潜力”：

* **结果评估**：评估最终交付物的质量（正确性、完整性、可用性）。
* **过程评估**：评估任务执行的表现（效率、方法、步骤合理性）。
* **能力评估**：评估 AI 的综合水平（认知、推理、交互、安全）。

---

## 📏 四大裁判维度 (Total: 100)

| 维度 | 分值 | 核心考察点 |
| :--- | :--- | :--- |
| **任务执行能力** | 30分 | 工具选择合理性、执行效率、结果正确性 |
| **认知与推理智能** | 30分 | 需求理解、问题分析、方案设计合理性 |
| **用户体验与交互质量** | 25分 | 沟通清晰度、进度可见性、反馈及时性 |
| **安全可靠与对齐** | 15分 | 安全防护、错误恢复能力、边界情况处理 |

---

## 🛠️ 裁判适用范围

* **基础对话**：纯逻辑理解与沟通能力评估。
* **工具链监控**：内置工具及自定义 **MCP 服务** 调用审计。
* **Agent 协作**：子 Agent 的委派精度与结果整合能力。
* **组合场景**：MCP + Skills + Agent 的混合编排效率。

---

## 🚦 裁判等级划分

* **S级 (90-100)**：**卓越** - 专家级表现，路径最优，几乎完美。
* **A级 (80-89)**：**优秀** - 高质量完成，仅存在非关键性小瑕疵。
* **B级 (70-79)**：**良好** - 满足需求，但执行效率或边界处理有提升空间。
* **C/D级 (<70)**：**不及格** - 存在重大逻辑错误或未能有效完成任务。

---

## 📈 扩展功能 (Roadmap)

* **历史趋势分析**：识别 AI 模型在长时间跨度下的改进方向。
* **自动化裁判建议**：基于评分结果自动生成优化建议。
* **多模型对比**：横向测评不同 LLM 在同一场景下的表现。
